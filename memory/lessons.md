# Trading Lessons

반복적으로 검증된 원칙만 기록한다. 단일 거래의 손익만으로 전략을 변경하지 않는다.

## Active lessons

1. **실시간 상태 우선** — Git 기억과 broker/MCP 값이 다르면 broker/MCP를 따른다.
2. **STALE이면 거래 금지** — cash, quote, policy 등 핵심 입력이 stale/blocked이면 NO_TRADE다.
3. **외부 보유분 권한 준수** — 수동/외부 매수분은 sellAuthorizedQuantity 범위를 넘겨 자동매도하지 않는다.
4. **추격매수 금지** — 최신 Toss 시세에서 과도하게 이탈한 지정가로 진입하지 않는다.
5. **물타기 금지** — 손실 포지션 평균단가 낮추기를 자동화하지 않는다.
6. **단타 최소 손익비 2:1** — 명확한 무효화 기준과 최소 기대 손익비가 없으면 진입하지 않는다.
7. **기록과 주문의 멱등성 분리** — Git push 실패를 이유로 주문을 반복 제출하지 않는다.

## Review rule

교훈을 수정할 때는 해당 변경의 근거가 된 거래 표본, 시장 국면, 반대 사례를 함께 기록한다.
