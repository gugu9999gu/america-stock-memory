# america-stock-memory

미국주식 자동매매/투자 의사결정의 외부 장기기억 저장소입니다.

이 저장소는 **거래 실행 시스템의 대체물이 아닙니다.** 실제 주문 가능 여부, 현금, 보유수량, 매도 가능수량, 체결상태, 시장 개장 여부는 매 회차 브로커/MCP의 최신 값을 최우선으로 사용합니다. Git 기록은 과거 판단과 학습을 복원하기 위한 보조 원장입니다.

## 핵심 파일

- `MEMORY_PROTOCOL.md` — 모든 자동매매/분석 작업이 따라야 할 읽기·쓰기 규칙
- `memory/current_state.json` — 최근 알려진 전략/리스크/세션 상태의 요약 캐시
- `memory/ledger.jsonl` — append-only 거래·NO_TRADE·리스크 이벤트 원장
- `memory/lessons.md` — 반복적으로 검증된 교훈과 전략 수정 이력

## 보안 원칙

계좌번호, 이메일, 비밀번호, API 키, 토큰, 인증정보 등 비밀정보는 절대 기록하지 않습니다. 주문/체결 식별자는 필요할 때에도 외부 공개에 안전한 비식별 값만 남깁니다.

## 데이터 우선순위

1. 브로커/MCP의 현재 live 상태와 공식 시장 데이터
2. 최신 1차 출처(SEC, 기업 IR, Federal Reserve, BLS, BEA 등)
3. 이 저장소의 최근 기록
4. 오래된 메모/가설

Git 기록과 브로커 상태가 충돌하면 브로커 상태를 따르고, 충돌 사실을 `memory/ledger.jsonl`에 기록합니다.
